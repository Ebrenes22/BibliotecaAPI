📚 API RESTful Biblioteca

API RESTful desarrollada con **ASP.NET Core** y **Entity Framework Core** para la gestión de autores y libros, siguiendo principios de arquitectura limpia y buenas prácticas de desarrollo.

 🚀 Tecnologías

* .NET 9
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* Swagger / OpenAPI

🔄 Endpoints

Autores

* GET `/api/autores`
* GET `/api/autores/{id}`
* POST `/api/autores`
* PUT `/api/autores/{id}`
* DELETE `/api/autores/{id}`

Libros

* GET `/api/libros`
* GET `/api/libros/{id}`
* POST `/api/libros`
* PUT `/api/libros/{id}`
* DELETE `/api/libros/{id}`
